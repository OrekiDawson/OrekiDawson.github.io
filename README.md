# Web 部署副本

本目录是 Web 站点的部署副本，不是第二个源码仓库，也不是功能开发入口。

## 1. 职责

### 1.1 来源

功能修改只发生在 `web/AD-Oreki-Edition/`。本目录由同步/部署流程从源码仓库生成或更新。

### 1.2 内容

本目录只保留可部署的站点文件、部署所需配置和本部署说明。不要在这里直接实现游戏功能。

## 2. 发布流程

1. 在 Web 源码仓库完成修改、定向测试和中文提交；
2. 生成或同步部署副本；
3. 对比源仓库与副本的提交/文件清单；
4. 部署到目标 Pages 站点；
5. 从线上地址检查实际页面、资源和关键功能；
6. 记录部署提交、时间、线上结果和未覆盖范围。

本地静态服务器可用不等于线上部署成功。部署失败不得把部分同步写成完整发布。

## 3. 回滚

回滚必须选择已核对的历史源码提交或部署产物，先保存当前线上状态，再执行同步和线上检查。禁止直接从本目录手工拼接功能文件。

## 4. 规则入口

规则入口使用 [Web 规则索引](../../AD-Oreki-Edition/docs/RULES_INDEX.md)。部署副本不复制规则正文。

## 5. 安全

不要在本目录、Git 历史或部署产物中保存 OAuth、密码、Cookie、SSH 私钥或其他私人凭据。发布凭据只能由用户环境和发布工具管理。
