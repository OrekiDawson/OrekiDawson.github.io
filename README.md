# AD: Oreki Edition

基于 **Antimatter Dimensions** 的个人加速汉化版：默认 **10000×** 游戏速度，简体中文界面，附带独立的成就管理工具与存档管理工具。

非官方、非商业的个人修改版，与原作者 Hevipelle 及任何发行方无关。

---

## 快速开始

`index.html` 用 `<script type="module">` 加载，浏览器**不允许**在 `file://` 下加载 ES 模块，所以必须通过 `http://` 访问。

### Windows（推荐）

双击 **`启动游戏.bat`**。脚本会依次尝试 Node.js / Python，启动本地服务器并自动打开浏览器。

### 手动启动（任意系统）

```bash
# 有 Node.js
node serve.mjs 8080

# 或有 Python
python -m http.server 8080 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8080/`。

> 两者都没有时，装一个即可：<https://nodejs.org> 或 <https://python.org>。
> 也可以用 VS Code 的 Live Server 插件打开 `index.html`。

### 手机

把整个目录部署到任意静态托管（GitHub Pages、Netlify 等），用手机浏览器访问该网址。
存档保存在浏览器 localStorage 里，**换设备或清浏览器数据会丢档**，重要的存档请用「存档工具 → 下载存档文件」导出留存。

## 游戏速度

默认 **10000×**，可在 **选项 → 游戏玩法 → 游戏速度** 里修改。

| 操作 | 说明 |
| --- | --- |
| 快捷按钮 | ×1 / ×10 / ×100 / ×1000 / ×10000 / ×100000 |
| 自定义输入 | 1 ~ 100000 之间的整数 |
| 恢复默认 | 一键回到 10000× |

设置保存在 `localStorage`（键名 `oreki-game-speed`），**不写入游戏存档**，所以：

- 刷新、关掉重开都保留；
- 把存档导出给别人，对方仍然用他自己的倍率；
- 导入别人的存档不会覆盖你当前的倍率。

上限 100000× 的原因：`realDiff = 墙钟 × 倍率` 是单点放大，倍率越高单帧推进的游戏时间越长，单个 tick 里要跑的生产、自动购买器、成就检查都会同步变多。10 万倍在 60fps 下约等于每帧推进 27 分钟游戏时间，仍能保持流畅；再往上会让低端手机掉帧，离线模拟的 tick 数也会逼近上限。

### 加速的边界

- **游戏时间**（生产、维度、无限/永恒/现实内的计时）按倍率推进。
- **现实时间**（存档里的 `realTime*` 类记录、统计页的「现实时间」、成就与挑战的真实时间判定）保持 1×，不会被加速 10000 倍。
- **黑洞**按 `sqrt(倍率)` 缩放（10000× 时为 100×），保留原设计里「黑洞是额外加速层」的意图，避免黑洞周期被放大到失去意义。
- **Pelle 毁灭态**下全局倍率同样降级为 `sqrt(倍率)`，与原版毁灭机制的削弱设定一致。
- 离线追赶（`simulateTime`）会把倍率计入，所以离线 1 小时在 10000× 下能追到很后面的进度；追赶期间倍率会被锁定为进入时的快照，中途改倍率不会造成时间错乱。

## 两个工具

都在 **选项 → 游戏玩法** 底部，**默认不启用，必须自己点开、自己确认**。

### 成就管理工具

弹窗里选范围（普通 / 隐藏 / 全部）和 ID 区间，先预览「将解锁多少个」，勾选风险确认后才会出现「解锁」按钮。

- 走的是游戏自己的解锁函数，成就的正常联动（自动购买器、缓存、提示）都会照常触发。
- 只写成就位图，不会改其它存档字段。
- **这是作弊功能。** 用了之后存档的成就进度就不可信了，请自行决定。

### 存档管理工具

- 查看当前存档的基本信息（版本、时间、成就数等）
- 立即备份 / 恢复上次备份（都存在浏览器本地，不上传任何服务器）
- 复制存档文本 / 下载存档文件
- 导入存档文本（先校验格式与版本，版本高于当前会拒绝）
- 重置存档（两步确认）

任何会覆盖当前存档的操作（导入、恢复、重置）之前，都会**自动写一份备份**到 `localStorage`（键名 `oreki-save-backup`）。

## 已知限制

- 汉化基线本身**没有翻译游戏内的 1400 余条滚动彩蛋新闻**（ADChinese 原样如此），所以顶部新闻栏会夹杂英文。这不影响任何机制。
- 主题名（Normal / Metro / Dark …）保留英文：主题名同时是存档里 `player.options.theme` 的取值，改名会让旧存档的主题设置失效。
- 后期内容（天神、Pelle 的完整推进、Lai'tela、Glyph 长期养成）只做了时间语义层面的自动化验证与静态代码核查，没有从零完整通关验证。
- 手机端只在桌面 Edge 的移动模拟下验证过布局与触控尺寸，未在真机上实测。
