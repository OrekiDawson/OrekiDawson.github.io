# Pages 部署仓库目录与中文命名约定

本仓库用于 <https://oreki.net> 的**已验证网页发布副本**，不是 Web 游戏源码开发场所。玩家可见说明、发布记录和维护文档用简体中文，但不批量更改静态资源 URL 或工具链文件名。

## 根目录说明

| 路径 | 用途 |
| --- | --- |
| `index.html`、`src/`、`public/`、`modules/` | 必须和已验收 Web 源码同步的站点资源，保持引用路径不变 |
| `CNAME`、`.nojekyll`、`Ads.txt` | GitHub Pages / 站点部署约定，未经专门验证不移动或更名 |
| `.github/`、`AGENTS.md`、`CLAUDE.md` | CI、发布与 Agent 标准文件 |
| `LICENSE`、`MOD-LICENSE`、`NOTICE.md` | 许可证与第三方声明，保留标准文件名 |
| `README.md`、`docs/` | 唯一根说明入口与中文维护文档 |
| `archive/` | 历史暂停及过期状态证据（`archive/项目暂停记录.md`） |
| `serve.mjs`、`启动游戏.bat` | 本地只读预览辅助入口 |

## 约束

- 不在 Pages 仓库直接修改功能 JS、存档格式、商店数值或逻辑；先在 [Web 源码仓库](https://github.com/OrekiDawson/AD-Oreki-Edition-Web) 开发并验证，再通过现有发布流程复制。
- 中文化只改允许变动的说明内容。不能重命名 `CNAME`、`index.html`、`src/`、`public/` 或已有线上路由来追求“全中文”。
- 新专题说明放 `docs/`，历史状态放 `archive/`；根目录不新建临时轮次报告、测试日志或私人配置。
- 线上提交必须经过既有 Required Checks 和部署验证，不能把文档 PR 当作成功部署；存档与运行证据不可伪造。
